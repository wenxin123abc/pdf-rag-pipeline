# 检索工具契约与评测

## 工具契约

Agent 只通过这五个动作接触 PDF，不允许"把整本塞进上下文"。

| 工具 | 输入 | 输出 | 何时调用 |
|---|---|---|---|
| `search_pdf` | query, k, 类型过滤 | 片段列表（含 page、chunk_id、score、snippet） | 大多数问题的第一步 |
| `read_page` | page | 该页全文 | 片段不够、需要看整页上下文 |
| `extract_table` | table_id 或页码 | 结构化表格 | 涉及数值、对比、汇总 |
| `analyze_chart` | image_id | 图表结论 | 涉及趋势、结构、示意图 |
| `quote_source` | chunk_id | 原文片段 + 页码锚点 | 需要给出引用时 |

本地实现对应 `pdf_tools.py` 的 `search` / `read` / `table` / `image` / `quote` / `stats`。`table` 和 `image` 支持按页码或唯一 ID 读取；图表结论由视觉模型生成描述后用 `apply_visual_descriptions.py` 回填。

## 路由规则

不同问题类型走不同路径，一律用 `search` 起手会浪费召回。

| 问题类型 | 例子 | 路径 |
|---|---|---|
| 简单事实 | "合同编号是多少" | `search` → 命中的 section 直接答 |
| 需要上下文 | "这条款的上一条是什么" | `search` → `read_page` 展开整页 |
| 数值 / 对比 | "预付款比例多少" / "各阶段金额对比" | `search --type table` → `table --id ...` |
| 跨章节综合 | "违约责任和付款条款有什么关联" | 多次 `search` → 规划阅读路径 → 汇总 |
| 图表趋势 | "这个图说明什么" | `search --type image` → `image --id ...` → 视觉描述 |
| 聚合统计 | "出现最多的 3 类违约情形" | 查预计算 chunk，**不要逐条召回** |

## 检索实现要点

- **BM25 + 中文 unigram/bigram**：英文/数字按词切，中文同时保留单字和双字，避免单词查询完全失配。零第三方依赖，适合小到中型文档。
- **检索字段**：用 `embed_text`（含上下文前缀），不是 `text`。
- **必须回页码**：任何检索结果都要带 `page` 和 `chunk_id`，否则无法溯源。
- **类型过滤**：`--type table` 能让数值类问题的信噪比明显提升。
- **无命中**：文本模式明确返回“未命中”，`--json` 返回空数组，不回退到零分无关 chunk。

文档规模上来后（数万 chunk）再换向量检索，但**页码与 chunk_id 的透传必须保留**，这是可追溯性的前提。

## 评测指标

不能只看"答案对不对"。四个维度都要有：

| 指标 | 定义 | 目标 |
|---|---|---|
| 答案正确率 | 与标准答案语义一致的比例 | 业务决定 |
| 检索命中率 | 正确片段出现在 top-k 的比例 | ≥ 90% |
| 页码准确率 | 引用页码与原文一致的比例 | ≥ 98%（合同/财报类必须高） |
| 表格数值一致率 | 答案数字与表格原值完全一致的比例 | 100%（错一个数字即事故） |
| 图表结论真实性 | 结论能在图上找到依据的比例 | 人工抽检 |

评测集构造：从真实文档里抽 30-50 条问题，覆盖上述六种问题类型，每条标注正确答案 + 正确页码 + 依据 chunk_id。

## 防幻觉

三道闸：

1. **强制引用**：回答必须带页码，或直接给出原文片段。没有依据就说"文档中未找到"，不要推测。
2. **页码可跳转**：前端渲染时点击引用能定位到页面 `bbox` 位置。`quote_anchor` 字段就是为此准备。
3. **数值二次核对**：涉及金额、比例、日期时，回 `quote` 取表格原值核对，不要用模型复述的数字。

## 离线预计算

聚合统计类问题用检索答不了，原因很直接：向量检索是"找相似片段"，而"哪三类违约情形出现最多"需要"对全文档计数"。这类必须提前算：

| 问题形态 | 预计算产物 |
|---|---|
| "出现最多的 N 类 X" | 分类统计表，每类附典型条款的 page + chunk_id |
| "所有金额加起来是多少" | 汇总表 |
| "哪些条款提到了 X" | 倒排索引：关键词 → 条款清单（带页码） |

产物写成独立 chunk（`chunk_type` 可复用 `table`），标注 `precomputed: true`，检索时优先命中。

## 失败排查

| 现象 | 首查 |
|---|---|
| 检索完全不命中 | 该内容是否为扫描页/图表（`stats` 看 image chunk 是否回填了描述） |
| 命中了但答不对 | 片段是否被切断（回 Step 2 看段落重建） |
| 页码对不上 | 用的是 `page` 字段还是 PDF 内置页码标签？两者可能差一页（封面不计页码） |
| 同一问题两次答不同 | 表格数值被多处索引，需去重 |
